# US-002 — Search and filter the catalogue

**State:** Ready · **Points:** 3 · **Sprint:** 1 · **Parent:** [[EPIC-001]]

## Story

As a visitor, I want to narrow the catalogue down, so that I can find a particular
kind of product without reading all of them.

## Acceptance criteria

1. Given the catalogue is showing, when I type into the search box, then only
   products whose name matches what I typed remain.
2. Given the catalogue is showing, when I choose a category, then only products in
   that category remain.
3. Given I have both a search term and a category selected, when the list renders,
   then both narrow the results together.
4. Given my search and filter match nothing, when the list renders, then I see a
   "no results" message and a way to clear the filters.
