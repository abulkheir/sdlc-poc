# US-012 — Be unable to touch another seller's listings

**State:** Ready · **Points:** 3 · **Sprint:** 2 · **Parent:** [[EPIC-001]]

## Story

As a seller, I want other sellers to be unable to alter my listings, so that I can
trust the marketplace with my products.

## Acceptance criteria

1. Given a listing belongs to another seller, when I ask the API to edit it, then it
   refuses — whatever the interface shows.
2. Given a listing belongs to another seller, when I ask the API to delete it, then
   it refuses.
3. Given a listing belongs to another seller, when I list my own products, then it
   is not among them.
4. Given the refusal happens, when it is returned, then it does not reveal whether
   the listing exists.
