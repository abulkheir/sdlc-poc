# US-009 — Be prevented from ordering more than is in stock

**State:** Ready · **Points:** 3 · **Sprint:** 2 · **Parent:** [[EPIC-001]]

## Story

As a seller, I want buyers to be unable to order more than I hold, so that I am not
committed to something I cannot supply.

## Acceptance criteria

1. Given a product has five in stock, when a buyer asks for six, then the request is
   refused and the cart is unchanged.
2. Given the refusal happens, when the buyer sees it, then the message says how many
   are available.
3. Given a buyer bypasses the interface and calls the API directly, when they ask for
   more than is in stock, then the API refuses. The rule lives on the server.
4. Given a product has no stock, when a buyer tries to add it, then they are refused.
